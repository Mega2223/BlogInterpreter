# BlogInterpreter  

Interpretador do blog do [mega2223.github.io](https://mega2223.gihub.io)  

O BlogInterpreter é uma aplicação java desktop que faz uma interpretação de arquivos para um formato HTML legível, a ideia é eu não ter que fazer uma página HTML toda vez que eu quiser inserir alguma coisa no meu blog.   

Ele tem suporte a
- Conversão (bem básica) de arquivos markdown para arquivos HTML
- Uso de stylesheets, mídia e scripts em JS de forma dinâmica
